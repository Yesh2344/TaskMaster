# TaskMaster![License](https://img.shields.io/badge/license-MIT-green)![React](https://img.shields.io/badge/react-18.2.0-blue)![Build](https://img.shields.io/badge/build-passing-brightgreen)

TaskMaster is a modern React application that demonstrates a full‑featured task management UI with authentication. 
It showcases:

* Secure login flow with JWT handling
* CRUD operations on tasks
* Centralised API client with error handling
* Custom hooks & context for authentication state
* Unit tests with React Testing Library
* Type‑friendly code with JSDoc annotations
